# Asset inbox

This folder is a drop box for files you'd like on the website: logos, photos, artwork, graphics, fonts, PDFs (such as
Street Team flyers), anything.

**Nothing in this folder is published.** A file only appears on the site once it has been placed into a page, so you
can drop things here freely, including drafts.

## How to add files

1. Open this folder on GitHub (you're probably looking at it now).
2. Click **Add file**, then **Upload files**.
3. Drag your files in, or click "choose your files".
4. In the box at the bottom, write a short note about what the files are.
5. Click **Commit changes**.

## Tell us what each file is for

Add a line for each file to the list below (click the pencil icon at the top of this page to edit it), or put the
same information in the note when you upload. For example: "crest-2026.png: new crest for the top of every page" or
"knights-photo.jpg: for the Roundtable page, credit Jane Doe".

Please also say if a file must not be changed (cropped, recoloured) and who should be credited.
